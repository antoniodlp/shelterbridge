# Registry and Stays, Plan 1: Database Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and test the complete Supabase backend for sub-project 1. That covers schema, RLS, RPC functions, audit log, sign-up allowlist, storage and seed data. The frontend plans (Plan 2: web foundation, Plan 3: web features) then build on it without database changes.

**Architecture:** Everything lives in versioned SQL migrations under `supabase/migrations/`. Public tables, the view and the RPCs live in `public`, the schema PostgREST exposes. Internal helpers live in `app`, which is not exposed. Authorization is enforced entirely by RLS that calls `app.current_app_role()`. Every behavior is pinned by pgTAP tests in `supabase/tests/database/`, which run against the local Supabase stack.

**Tech Stack:**
- Supabase CLI (npm package `supabase`, run through npm scripts)
- Postgres 15+ with `pg_trgm`, `unaccent`, `btree_gist` and `pgtap`
- Docker Desktop for the local stack
- Node.js 20+ for the CLI and one generator script

**Spec:** [docs/superpowers/specs/2026-10-07-shelterbridge-registry-and-stays-design.md](../specs/2026-10-07-shelterbridge-registry-and-stays-design.md)

## Global Constraints

- **Language:** code, identifiers, comments and commit messages are in English. Never use em dashes or en dashes in any file, comment or commit message.
- **Function shape:** every SQL function has `set search_path = ''` and fully qualifies objects (`public.`, `app.`, `auth.`, `extensions.`, `storage.`). There is one exception: the `tests.authenticate_as`, `tests.authenticate_as_anon`, `tests.reset_auth` and `tests.set_operator_name` helpers have no `SET` clause, because a function-level `SET` would undo their `set_config` calls on exit.
- **Business errors** are raised as `raise exception using errcode = 'P0001', message = '<code>'`. The only codes allowed are `not_authorized`, `not_found`, `validation`, `already_checked_in`, `stay_not_open`, `outing_already_open`, `no_open_outing`, `outing_exception_needs_confirmation`, `outing_outside_stay`, `overlapping_stays` and `merge_same_person`.
- **Every table in `public`:**
  - has RLS enabled;
  - runs `revoke all on table ... from anon`;
  - has `created_at`, `created_by`, `updated_at` and `updated_by` filled by the `app.stamp()` trigger (except `audit_log`).
- **Every RPC in `public`:**
  - is `security invoker`;
  - runs `revoke all on function ... from public, anon`;
  - runs `grant execute on function ... to authenticated`.
- **Time:**
  - "Today" is `app.today()`, and day boundaries use `app.local_date(timestamptz)`. Both use the shelter timezone stored in `settings` (default `America/Mexico_City`).
  - Never use `current_date` or UTC dates for business rules. `current_date` is acceptable only in seed data for computing ages.
- **Data:**
  - All seed and test data is fictitious.
  - Test files use `@example.test` emails and UUIDs of the form `00000000-0000-4000-8000-000000000NNN`.
  - Seed data uses `@shelterbridge.test` emails and UUIDs of the form `b0000000-0000-4000-8000-0000000000NN`.
- **Migrations:** files are named `YYYYMMDDHHMMSS_name.sql` using the exact names given in each task. Never edit a migration from an earlier task. Add a new one instead.
- **Commands** run from the repository root. Docker Desktop must be running for every `db:*` script.

## Review Focus

1. Whitespace-only text. A first name of only spaces is rejected; a last name, region, bed, notes or comment of only spaces is stored as null. Tests: Task 5 (people), Task 6 (bed), Task 7 (comment).
2. Dates or times in the future. A birth date, entry date, check-out date or outing time later than now is rejected with `validation`. Tests: Task 5, Task 6, Task 7, Task 10.
3. Same-day re-admission. A person checked out today, for example by mistake, can be checked in again today without a false `overlapping_stays`. Tests: Task 6 (direct insert) and Task 10 (`check_in`).
4. Search input that is one character long or contains `%` or `_`. It returns no results instead of matching everyone. Tests: Task 12.
5. A person with an unknown birth date. Their age is null and they are never flagged as an unaccompanied minor, without erroring. Tests: Task 9.

Create `supabase/tests/database/000-setup-tests-hooks.test.sql`:

```sql
-- Shared pgTAP helpers. This file sorts first, and the statements outside the
-- transaction below persist in the local database for the other test files.
create extension if not exists pgtap with schema extensions;

create schema if not exists tests;
grant usage on schema tests to anon, authenticated;

-- Creates an auth user. When p_role is given, also creates an active invitation.
create or replace function tests.create_user(p_email text, p_role text default null)
returns uuid
language plpgsql
security definer
set search_path = ''
as $$
declare
  v_id uuid := gen_random_uuid();
begin
  insert into auth.users (
    id, instance_id, aud, role, email, raw_app_meta_data, raw_user_meta_data, created_at, updated_at)
  values (
    v_id, '00000000-0000-0000-0000-000000000000', 'authenticated', 'authenticated', p_email,
    '{"provider": "email", "providers": ["email"]}', '{}', now(), now());
  if p_role is not null then
    insert into public.app_users (email, role, display_name)
    values (p_email, p_role::public.app_role, p_email);
  end if;
  return v_id;
end;
$$;

create or replace function tests.user_id(p_email text)
returns uuid
language sql
stable
security definer
set search_path = ''
as $$
  select u.id from auth.users u where u.email = p_email
$$;

-- No SET clause on the next four functions: it would undo set_config on exit.
create or replace function tests.authenticate_as(p_email text)
returns void
language plpgsql
as $$
declare
  v_id uuid := tests.user_id(p_email);
begin
  if v_id is null then
    raise exception 'tests.authenticate_as: no user %', p_email;
  end if;
  perform pg_catalog.set_config('role', 'authenticated', true);
  perform pg_catalog.set_config(
    'request.jwt.claims',
    pg_catalog.json_build_object('sub', v_id, 'role', 'authenticated', 'email', p_email)::text,
    true);
end;
$$;

create or replace function tests.authenticate_as_anon()
returns void
language plpgsql
as $$
begin
  perform pg_catalog.set_config('role', 'anon', true);
  perform pg_catalog.set_config('request.jwt.claims', '{"role": "anon"}', true);
end;
$$;

create or replace function tests.reset_auth()
returns void
language plpgsql
as $$
begin
  perform pg_catalog.set_config('role', 'postgres', true);
  perform pg_catalog.set_config('request.jwt.claims', '', true);
end;
$$;

create or replace function tests.set_operator_name(p_name text)
returns void
language plpgsql
as $$
begin
  perform pg_catalog.set_config(
    'request.headers',
    pg_catalog.json_build_object(
      'x-operator-name',
      pg_catalog.replace(pg_catalog.encode(pg_catalog.convert_to(p_name, 'UTF8'), 'base64'), E'\n', ''))::text,
    true);
end;
$$;

begin;
select plan(1);
select ok(true, 'test helpers are installed');
select * from finish();
rollback;
```

Create `supabase/migrations/20261007000100_users_and_roles.sql`:

```sql
-- Users, roles and the sign-up allowlist.

create extension if not exists pg_trgm with schema extensions;
create extension if not exists unaccent with schema extensions;
create extension if not exists btree_gist with schema extensions;

-- anon never touches application data. Each table also revokes anon explicitly.
alter default privileges for role postgres in schema public revoke all on tables from anon;
alter default privileges for role postgres in schema public revoke all on sequences from anon;
alter default privileges for role postgres in schema public revoke all on functions from anon;

-- Internal helpers live in "app", which PostgREST does not expose.
create schema if not exists app;
grant usage on schema app to authenticated;

-- Fills audit columns. Clients cannot override them.
create function app.stamp()
returns trigger
language plpgsql
set search_path = ''
as $$
begin
  if tg_op = 'INSERT' then
    new.created_at := now();
    new.created_by := auth.uid();
  else
    new.created_at := old.created_at;
    new.created_by := old.created_by;
  end if;
  new.updated_at := now();
  new.updated_by := auth.uid();
  return new;
end;
$$;

create type public.app_role as enum ('admin', 'legal', 'psychology', 'volunteer');

create table public.app_users (
  email        text primary key,
  user_id      uuid unique references auth.users (id) on delete set null,
  role         public.app_role not null,
  display_name text not null check (length(trim(display_name)) > 0),
  active       boolean not null default true,
  created_at   timestamptz not null default now(),
  created_by   uuid,
  updated_at   timestamptz not null default now(),
  updated_by   uuid,
  constraint app_users_email_normalized check (email = lower(trim(email)) and email like '%_@_%')
);

revoke all on table public.app_users from anon;

-- Normalizes the email and links the invitation to an existing auth user.
create function app.prepare_app_user()
returns trigger
language plpgsql
security definer
set search_path = ''
as $$
begin
  new.email := lower(trim(new.email));
  if tg_op = 'INSERT' or new.email is distinct from old.email then
    select u.id into new.user_id
    from auth.users u
    where lower(u.email) = new.email;
  end if;
  return new;
end;
$$;

create trigger app_users_prepare
  before insert or update on public.app_users
  for each row execute function app.prepare_app_user();

create trigger app_users_stamp
  before insert or update on public.app_users
  for each row execute function app.stamp();

-- Links an invitation when its auth user is created later (first sign-in).
create function app.link_new_auth_user()
returns trigger
language plpgsql
security definer
set search_path = ''
as $$
begin
  update public.app_users
  set user_id = new.id
  where email = lower(new.email)
    and user_id is null;
  return new;
end;
$$;

create trigger link_app_user
  after insert on auth.users
  for each row execute function app.link_new_auth_user();

-- The caller's role, read on every statement so deactivation is immediate.
create function app.current_app_role()
returns public.app_role
language sql
stable
security definer
set search_path = ''
as $$
  select au.role
  from public.app_users au
  where au.user_id = auth.uid()
    and au.active
$$;

alter table public.app_users enable row level security;

create policy app_users_select on public.app_users
  for select to authenticated
  using (user_id = (select auth.uid()) or (select app.current_app_role()) = 'admin');

create policy app_users_insert on public.app_users
  for insert to authenticated
  with check ((select app.current_app_role()) = 'admin');

create policy app_users_update on public.app_users
  for update to authenticated
  using ((select app.current_app_role()) = 'admin')
  with check ((select app.current_app_role()) = 'admin');

-- Auth hook: only invited, active emails may create an account (Google or password).
create function public.hook_before_user_created(event jsonb)
returns jsonb
language plpgsql
security definer
set search_path = ''
as $$
declare
  v_email text := lower(trim(event -> 'user' ->> 'email'));
begin
  if exists (select 1 from public.app_users au where au.email = v_email and au.active) then
    return '{}'::jsonb;
  end if;
  return jsonb_build_object(
    'error', jsonb_build_object(
      'http_code', 403,
      'message', 'This email has not been invited to ShelterBridge.'));
end;
$$;

revoke all on function public.hook_before_user_created(jsonb) from public, anon, authenticated;
grant execute on function public.hook_before_user_created(jsonb) to supabase_auth_admin;
```

```js
  return `  (${quote(code)}, ${quote(labels)}::jsonb, ${sortOrder})`
```

```sql
immutable

strict

immutable
```

```sql
-- Outings: temporary exits during a stay ("salida"). Not to be confused with check-out.

create table public.outings (
  id           uuid primary key default gen_random_uuid(),
  stay_id      uuid not null references public.stays (id) on delete cascade,
  left_at      timestamptz not null default now(),
  returned_at  timestamptz,
  is_exception boolean not null default false,
  comment      text,
  created_at   timestamptz not null default now(),
  created_by   uuid,
  updated_at   timestamptz not null default now(),
  updated_by   uuid,
  constraint outings_return_after_leave check (returned_at is null or returned_at > left_at)
);

revoke all on table public.outings from anon;

create unique index outings_one_open_per_stay on public.outings (stay_id) where returned_at is null;
create index outings_stay_id on public.outings (stay_id);

create function app.check_outing()
returns trigger
language plpgsql
set search_path = ''
as $$
declare
  v_entry date;
  v_exit date;
begin
  new.comment := nullif(trim(new.comment), '');
  if new.left_at > now() or new.returned_at > now() then
    raise exception using errcode = 'P0001', message = 'validation';
  end if;
  select s.entry_date, s.exit_date into v_entry, v_exit
  from public.stays s
  where s.id = new.stay_id;
  if app.local_date(new.left_at) < v_entry
     or (v_exit is not null and app.local_date(new.left_at) > v_exit) then
    raise exception using errcode = 'P0001', message = 'outing_outside_stay';
  end if;
  return new;
end;
$$;

create trigger outings_check
  before insert or update on public.outings
  for each row execute function app.check_outing();

create trigger outings_stamp
  before insert or update on public.outings
  for each row execute function app.stamp();

-- The other direction: editing a stay's dates may not strand one of its outings.
create function app.check_stay_keeps_outings()
returns trigger
language plpgsql
set search_path = ''
as $$
begin
  if exists (
    select 1
    from public.outings o
    where o.stay_id = new.id
      and (app.local_date(o.left_at) < new.entry_date
           or (new.exit_date is not null and app.local_date(o.left_at) > new.exit_date))
  ) then
    raise exception using errcode = 'P0001', message = 'outing_outside_stay';
  end if;
  return new;
end;
$$;

create trigger stays_keep_outings
  before update of entry_date, exit_date on public.stays
  for each row execute function app.check_stay_keeps_outings();

alter table public.outings enable row level security;

create policy outings_select on public.outings for select to authenticated
  using ((select app.current_app_role()) is not null);
create policy outings_insert on public.outings for insert to authenticated
  with check ((select app.current_app_role()) is not null);
```

```sql
create table public.audit_log (
  id            bigint generated always as identity primary key,
  at            timestamptz not null default now(),
  actor_user_id uuid,
  actor_role    public.app_role,
  operator_name text,
  table_name    text not null,
  record_id     text not null,
  action        text not null check (action in ('insert', 'update', 'delete', 'merge')),
  old_data      jsonb,
  new_data      jsonb
);

revoke all on table public.audit_log from anon;
revoke insert, update, delete, truncate on table public.audit_log from authenticated;

create index audit_log_record on public.audit_log (table_name, record_id);
create index audit_log_at on public.audit_log (at desc);

alter table public.audit_log enable row level security;

create policy audit_log_select on public.audit_log for select to authenticated
  using ((select app.current_app_role()) = 'admin');

-- The volunteer on shift, sent by the web app as base64 UTF-8. Attribution only.
create function app.operator_name()
returns text
language plpgsql
stable
set search_path = ''
as $$
declare
  v_encoded text;
begin
  v_encoded := nullif(current_setting('request.headers', true), '')::json ->> 'x-operator-name';
  if v_encoded is null then
    return null;
  end if;
  return nullif(trim(convert_from(decode(v_encoded, 'base64'), 'UTF8')), '');
exception
  when others then
    return null;
end;
$$;

create function app.write_audit(p_table text, p_record_id text, p_action text, p_old jsonb, p_new jsonb)
returns void
language plpgsql
security definer
set search_path = ''
as $$
begin
  insert into public.audit_log (
    actor_user_id, actor_role, operator_name, table_name, record_id, action, old_data, new_data)
  values (
    auth.uid(), app.current_app_role(), app.operator_name(), p_table, p_record_id, p_action, p_old, p_new);
end;
$$;

-- Trigger argument: the key column (default "id").
create function app.audit()
returns trigger
language plpgsql
security definer
set search_path = ''
as $$
declare
  v_key text := coalesce(tg_argv[0], 'id');
  v_old jsonb := case when tg_op in ('UPDATE', 'DELETE') then to_jsonb(old) end;
  v_new jsonb := case when tg_op in ('INSERT', 'UPDATE') then to_jsonb(new) end;
begin
  perform app.write_audit(tg_table_name, coalesce(v_new, v_old) ->> v_key, lower(tg_op), v_old, v_new);
  return null;
end;
$$;

create trigger audit after insert or update or delete on public.people
  for each row execute function app.audit();

  for each row execute function app.audit();
```

```sql
-- Registration, check-in and check-out.

create function app.require_role()
returns public.app_role
language plpgsql
stable
set search_path = ''
as $$
declare
  v_role public.app_role := app.current_app_role();
begin
  if v_role is null then
    raise exception using errcode = 'P0001', message = 'not_authorized';
  end if;
  return v_role;
end;
$$;

-- Opens a stay. Concurrent check-ins from two computers end in already_checked_in.
create function app.insert_stay(p_person_id uuid, p_stay jsonb)
returns uuid
language plpgsql
set search_path = ''
as $$
declare
  v_stay_id uuid;
begin
  if exists (select 1 from public.stays s where s.person_id = p_person_id and s.exit_date is null) then
    raise exception using errcode = 'P0001', message = 'already_checked_in';
  end if;
  insert into public.stays (person_id, entry_date, case_type_code, bed, phone_status, notes)
  values (
    p_person_id,
    coalesce((p_stay ->> 'entry_date')::date, app.today()),
    p_stay ->> 'case_type_code',
    p_stay ->> 'bed',
    coalesce(p_stay ->> 'phone_status', 'none'),
    p_stay ->> 'notes')
  returning id into v_stay_id;
  return v_stay_id;
exception
  when unique_violation then
    raise exception using errcode = 'P0001', message = 'already_checked_in';
  when exclusion_violation then
    raise exception using errcode = 'P0001', message = 'overlapping_stays';
end;
$$;

create function public.register_person_and_check_in(p_person jsonb, p_stay jsonb default '{}'::jsonb)
returns jsonb
language plpgsql
security invoker
set search_path = ''
as $$
declare
  v_person_id uuid;
  v_stay_id uuid;
begin
  perform app.require_role();
  insert into public.people (
    first_name, last_name, birth_date, birth_date_estimated, gender_code, country_code, region, carer_id)
  values (
    p_person ->> 'first_name',
    p_person ->> 'last_name',
    (p_person ->> 'birth_date')::date,
    coalesce((p_person ->> 'birth_date_estimated')::boolean, false),
    p_person ->> 'gender_code',
    p_person ->> 'country_code',
    p_person ->> 'region',
    (p_person ->> 'carer_id')::uuid)
  returning id into v_person_id;
  v_stay_id := app.insert_stay(v_person_id, coalesce(p_stay, '{}'::jsonb));
  return jsonb_build_object('person_id', v_person_id, 'stay_id', v_stay_id);
end;
$$;

create function public.check_in(p_person_id uuid, p_stay jsonb default '{}'::jsonb)
returns uuid
language plpgsql
security invoker
set search_path = ''
as $$
begin
  perform app.require_role();
  if not exists (
    select 1 from public.people p where p.id = p_person_id and p.merged_into_id is null
  ) then
    raise exception using errcode = 'P0001', message = 'not_found';
  end if;
  return app.insert_stay(p_person_id, coalesce(p_stay, '{}'::jsonb));
end;
$$;

-- Closes a stay. An open outing is left open: the person left and did not return.
create function public.check_out(p_stay_id uuid, p_exit_date date default null)
returns void
language plpgsql
security invoker
set search_path = ''
as $$
declare
  v_stay public.stays;
  v_exit date := coalesce(p_exit_date, app.today());
begin
  perform app.require_role();
  select * into v_stay from public.stays s where s.id = p_stay_id for update;
  if not found then
    raise exception using errcode = 'P0001', message = 'not_found';
  end if;
  if v_stay.exit_date is not null then
    raise exception using errcode = 'P0001', message = 'stay_not_open';
  end if;
  if v_exit < v_stay.entry_date or v_exit > app.today() then
    raise exception using errcode = 'P0001', message = 'validation';
  end if;
  if exists (
    select 1 from public.outings o
    where o.stay_id = p_stay_id and app.local_date(o.left_at) > v_exit
  ) then
    raise exception using errcode = 'P0001', message = 'validation';
  end if;
  update public.stays set exit_date = v_exit where id = p_stay_id;
end;
$$;

revoke all on function public.register_person_and_check_in(jsonb, jsonb) from public, anon;
grant execute on function public.register_person_and_check_in(jsonb, jsonb) to authenticated;
revoke all on function public.check_in(uuid, jsonb) from public, anon;
grant execute on function public.check_in(uuid, jsonb) to authenticated;
revoke all on function public.check_out(uuid, date) from public, anon;
grant execute on function public.check_out(uuid, date) to authenticated;
```

```sql
-- Duplicate detection at registration and free-text search over the whole history.

create function public.find_possible_duplicates(
  p_first_name text,
  p_last_name text default null,
  p_birth_date date default null,
  p_country_code text default null)
returns table (
  person_id uuid,
  first_name text,
  last_name text,
  birth_date date,
  birth_date_estimated boolean,
  country_code text,
  photo_path text,
  score real,
  last_entry_date date,
  last_exit_date date)
language plpgsql
stable
security invoker
set search_path = ''
as $$
#variable_conflict use_column
declare
  v_q1 text := app.normalize_name(p_first_name, p_last_name);
  v_q2 text := app.normalize_name(p_last_name, p_first_name);
begin
  perform app.require_role();
  if v_q1 is null or length(v_q1) < 2 then
    return;
  end if;
  return query
  with scored as (
    select
      p.id,
      p.first_name,
      p.last_name,
      p.birth_date,
      p.birth_date_estimated,
      p.country_code,
      p.photo_path,
      greatest(
        extensions.similarity(p.search_name, v_q1),
        extensions.similarity(p.search_name, v_q2)) as name_sim,
      case
        when p_birth_date is null or p.birth_date is null then 0
        when p.birth_date = p_birth_date then 0.30
        when extract(year from p.birth_date) = extract(year from p_birth_date)
         and extract(month from p.birth_date) = extract(day from p_birth_date)
         and extract(day from p.birth_date) = extract(month from p_birth_date) then 0.20
        when extract(year from p.birth_date) = extract(year from p_birth_date) then 0.10
        else 0
      end as dob_bonus,
      case when p_country_code is not null and p.country_code = p_country_code then 0.10 else 0 end as country_bonus
    from public.people p
    where p.merged_into_id is null
  )
  select
    s.id,
    s.first_name,
    s.last_name,
    s.birth_date,
    s.birth_date_estimated,
    s.country_code,
    s.photo_path,
    (s.name_sim + s.dob_bonus + s.country_bonus)::real,
    ls.entry_date,
    ls.exit_date
  from scored s
  left join lateral (
    select st.entry_date, st.exit_date
    from public.stays st
    where st.person_id = s.id
    order by st.entry_date desc
    limit 1
  ) ls on true
  where s.name_sim >= 0.30
     or (s.name_sim >= 0.20 and s.dob_bonus >= 0.20)
  order by 8 desc
  limit 5;
end;
$$;

create function public.search_people(p_query text, p_limit integer default 50)
returns table (
  person_id uuid,
  first_name text,
  last_name text,
  birth_date date,
  birth_date_estimated boolean,
  country_code text,
  photo_path text,
  score real,
  last_entry_date date,
  last_exit_date date,
  has_open_stay boolean)
language plpgsql
stable
security invoker
set search_path = ''
as $$
#variable_conflict use_column
declare
  v_q text := app.normalize_name(p_query, null);
  v_like text;
begin
  perform app.require_role();
  if v_q is null or length(v_q) < 2 then
    return;
  end if;
  v_like := '%' || replace(replace(replace(v_q, '\', '\\'), '%', '\%'), '_', '\_') || '%';
  return query
  select
    p.id,
    p.first_name,
    p.last_name,
    p.birth_date,
    p.birth_date_estimated,
    p.country_code,
    p.photo_path,
    extensions.word_similarity(v_q, p.search_name)::real,
    ls.entry_date,
    ls.exit_date,
    exists (select 1 from public.stays os where os.person_id = p.id and os.exit_date is null)
  from public.people p
  left join lateral (
    select st.entry_date, st.exit_date
    from public.stays st
    where st.person_id = p.id
    order by st.entry_date desc
    limit 1
  ) ls on true
  where p.merged_into_id is null
    and (p.search_name like v_like or extensions.word_similarity(v_q, p.search_name) >= 0.5)
  order by (p.search_name like v_like) desc, 8 desc, p.search_name
  limit least(greatest(coalesce(p_limit, 50), 1), 200);
end;
$$;

revoke all on function public.find_possible_duplicates(text, text, date, text) from public, anon;
grant execute on function public.find_possible_duplicates(text, text, date, text) to authenticated;
revoke all on function public.search_people(text, integer) from public, anon;
grant execute on function public.search_people(text, integer) to authenticated;
```

```sql
-- Merge a duplicate person into a survivor. Nothing is deleted.

create function public.merge_people(p_survivor_id uuid, p_duplicate_id uuid)
returns void
language plpgsql
security invoker
set search_path = ''
as $$
begin
  if app.current_app_role() is distinct from 'admin' then
    raise exception using errcode = 'P0001', message = 'not_authorized';
  end if;
  if p_survivor_id = p_duplicate_id then
    raise exception using errcode = 'P0001', message = 'merge_same_person';
  end if;

  perform 1
  from public.people p
  where p.id in (p_survivor_id, p_duplicate_id)
  for update;

  if (
    select count(*)
    from public.people p
    where p.id in (p_survivor_id, p_duplicate_id)
      and p.merged_into_id is null
  ) <> 2 then
    raise exception using errcode = 'P0001', message = 'not_found';
  end if;

  if exists (
    select 1
    from public.stays a
    join public.stays b
      on daterange(a.entry_date, a.exit_date, '[)') && daterange(b.entry_date, b.exit_date, '[)')
    where a.person_id = p_survivor_id
      and b.person_id = p_duplicate_id
  ) then
    raise exception using errcode = 'P0001', message = 'overlapping_stays';
  end if;

  update public.stays
  set person_id = p_survivor_id
  where person_id = p_duplicate_id;

  update public.people
  set carer_id = case when id = p_survivor_id then null else p_survivor_id end
  where carer_id = p_duplicate_id;

  update public.people
  set merged_into_id = p_survivor_id
  where merged_into_id = p_duplicate_id;

  update public.people
  set merged_into_id = p_survivor_id
  where id = p_duplicate_id;

  perform app.write_audit(
    'people',
    p_duplicate_id::text,
    'merge',
    null,
    jsonb_build_object('survivor_id', p_survivor_id, 'duplicate_id', p_duplicate_id));
end;
$$;

revoke all on function public.merge_people(uuid, uuid) from public, anon;
grant execute on function public.merge_people(uuid, uuid) to authenticated;
```

## Interfaces for Plans 2 and 3

The web plans consume exactly this surface through `web/src/api/`.

**Tables (via PostgREST)**
- **`app_users`:**
  - admin: reads every row, invites (insert) and updates; there is no delete, deactivate instead;
  - everyone else: reads only their own row, to learn their role.
- **`settings`:** read by everyone; written by admin.
- **`countries`, `case_types`, `genders`:** read by everyone; insert and update by admin.
- **`people`:** select, insert and update for everyone, except that only an admin may set `merged_into_id` (hardening migration 20261007001400). Use `updated_at` for optimistic concurrency.
- **`stays`, `outings`:** select, insert and update for everyone (normal inserts go through the RPCs); only an admin may change `stays.person_id`; delete by admin only. Use `updated_at` for optimistic concurrency.
- **`audit_log`:** admin read only.

**View**
- `current_residents` (columns in Task 9).

**RPCs**

| Function | Returns |
|---|---|
| `register_person_and_check_in(p_person jsonb, p_stay jsonb)` | `{person_id, stay_id}` |
| `check_in(p_person_id uuid, p_stay jsonb)` | stay id |
| `check_out(p_stay_id uuid, p_exit_date date)` | void |
| `start_outing(p_stay_id uuid, p_comment text, p_confirm_exception boolean)` | outing id |
| `end_outing(p_stay_id uuid)` | outing id |
| `find_possible_duplicates(p_first_name text, p_last_name text, p_birth_date date, p_country_code text)` | up to 5 rows |
| `search_people(p_query text, p_limit integer)` | rows |
| `merge_people(p_survivor_id uuid, p_duplicate_id uuid)` | void |

**Errors**
- **Business errors:** `code = 'P0001'`, with one of the codes in Global Constraints as the `message`.
- **Database errors the web app must map:**

| Code | Meaning | Maps to |
|---|---|---|
| `42501` | RLS or privilege | `not_authorized` |
| `23505` | unique | `validation` |
| `23514` | check | `validation` |
| `23502` | not null | `validation` |
| `23503` | foreign key | `validation` |
| `22007`, `22008`, `22P02` | bad date or uuid text | `validation` |
| `23P01` | exclusion | `overlapping_stays` |

**Request header**
- `x-operator-name`: base64 of the UTF-8 operator name, sent only for the shared volunteer account.

**Storage**
- Bucket `person-photos`, paths `{person_id}.jpg` and `{person_id}_thumb.jpg`, JPEG only, 2 MB maximum.
